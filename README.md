# Photo Gallery

A simple, beautiful photo gallery website showcasing photos retrieved from a Google Drive folder.

## Live Site

Once GitHub Pages is enabled: https://lichengan12.github.io/photo-gallery/

## Features

- Responsive grid gallery
- Lightbox viewer with keyboard navigation (← → Esc)
- Optimized images for fast loading
- Modern dark theme
