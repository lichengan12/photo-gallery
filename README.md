# Photo Gallery

A simple, beautiful photo gallery website showcasing photos retrieved from a Google Drive folder.

**Repository:** https://github.com/lichengan12/photo-gallery

## Live Site

Enable GitHub Pages (Settings → Pages → Source: Deploy from a branch → main / root) then visit:
https://lichengan12.github.io/photo-gallery/

## Features

- Responsive grid gallery
- Lightbox viewer with keyboard navigation (← → Esc)
- Optimized images for fast loading
- Modern dark theme

## Adding the Photos

The 42 optimized photos are ready. To complete the site:

1. Clone the repo
2. Create a `photos/` folder
3. Copy the resized JPGs into `photos/` (the files are available from the original Google Drive or the conversion done in this session)
4. Commit and push

Alternatively, download the photos from the Drive folder, convert HEIC to JPG if needed, resize to ~1200px, and place them in `photos/` matching the filenames listed in `index.html`.
